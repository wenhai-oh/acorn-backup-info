Personal backup utility

Acorn OCI Backups

Acorn OCI Backups stores encrypted backups of selected application data in a Google Drive account chosen by its owner.

How it works

The utility runs on the owner's server and uses restic and rclone to create, verify, restore and maintain backup versions. Google authorization lets it access the owner's backup storage automatically.

This website provides information about the utility. It does not offer account registration, accept uploads or provide access to backup files.

Privacy and control

Backup contents are encrypted before upload. Access is controlled by the Google account owner, who can revoke authorization or remove the backup repository.
